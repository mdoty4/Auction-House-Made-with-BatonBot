# Auction House

> **⚠️ Important Notice: This project was created by BatonBot, an agentic engineering tool, for demonstration purposes.**
>
> **BatonBot** is designed to chain prompts in a sequence and use specified agents for each one. This application showcases the capabilities of agentic engineering — where AI-driven agents work together in a coordinated pipeline to plan, architect, and build full-stack software applications autonomously. Each stage of this project was handled by a dedicated agent, with prompts chained together to ensure consistency, quality, and proper integration across all layers.

## Overview

Auction House is a full-stack eBay-inspired auction marketplace application. It supports real-time bidding, product listings, shopping cart functionality, order management, and user authentication — all built as a monorepo with a Next.js frontend and Express.js backend.

## Tech Stack

### Frontend
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Data Fetching:** TanStack Query (React Query)
- **Real-time:** Socket.IO Client

### Backend
- **Framework:** Express.js
- **ORM:** Prisma
- **Database:** PostgreSQL
- **Real-time:** Socket.IO Server
- **Authentication:** JWT-based auth

### Shared
- **Configuration:** Shared config module across workspaces
- **Language:** TypeScript (across all layers)

## Features

- **User Authentication** — Register, login, and JWT-based session management
- **Product Listings** — Browse, search, and create auction listings with categories
- **Real-time Bidding** — Live bid updates via WebSocket (Socket.IO)
- **Shopping Cart** — Add items, manage cart, and proceed to checkout
- **Order Management** — Track purchased and sold items
- **Seller Dashboard** — Manage active auctions and view sales

## Getting Started

### Prerequisites

- Node.js 18+
- PostgreSQL database
- npm (or pnpm/yarn)

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd auction-house
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up environment variables**
   ```bash
   cp .env.example .env
   # Edit .env with your database credentials and JWT secret
   ```

4. **Set up the database**
   ```bash
   cd backend
   npx prisma migrate dev
   npx prisma generate
   ```

5. **Seed the database (optional)**
   ```bash
   npm run db:seed
   ```

### Running the Application

Run both the frontend and backend:

```bash
# Terminal 1 - Backend
cd backend
npm run dev

# Terminal 2 - Frontend
cd frontend
npm run dev
```

- Frontend: `http://localhost:3000`
- Backend API: `http://localhost:4000`
